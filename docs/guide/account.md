# 账号与登录

BiliDanmu 支持多账号管理，并提供 TV 二维码登录方式，方便你在不同账号之间快速登录与切换。

## 登录方式

### TV 二维码登录（推荐）

BiliDanmu 使用 B 站 TV 端二维码登录，步骤如下：

1. 在「账号」页面点击「扫码登录」
2. 使用 B 站客户端扫描 TV 二维码
3. 确认后自动完成登录，获取 Cookie 凭证

登录成功后，BiliDanmu 会保存凭证到本地，下次启动自动恢复。

## 多账号管理

- **添加账号**：支持同时添加多个账号
- **切换账号**：在弹幕窗口内一键切换发送账号
- **切换发送账号**：可单独设置用于发送弹幕的账号（不同于主账号）
- **移除账号**：移除后本地凭证同步清除
- **匿名账号**：支持切换到匿名账号发送弹幕
- **自动恢复**：启动时自动恢复上次登录状态，无需重复登录
- **Cookie 刷新**：支持手动刷新 Cookie 延长有效期
- **账号信息刷新**：支持刷新账号头像、昵称等元信息

## 双凭证机制

BiliDanmu 内部维护两套凭证：

| 凭证 | 用途 |
| --- | --- |
| 主凭证 | WebSocket 连接、音频播放等观看相关 |
| 发送凭证 | 发送弹幕、表情等互动相关 |

发送凭证未设置时自动回退到主凭证，方便单账号用户使用。

## 安全提示

- 凭证数据仅保存在本地，不会上传到任何服务器
- 建议不要在公共设备上保存账号
- 移除账号会清除本地存储的敏感信息

## 常见问题

**Q：登录后提示「账号未登录」？**

A：请检查 Cookie 是否过期，或尝试重新扫码登录、刷新 Cookie。

**Q：切换账号后弹幕发送身份未更新？**

A：确认已在弹幕窗口的账号切换器中选择了目标发送账号。
