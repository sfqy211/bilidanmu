# 听视频

把视频的声音留在耳边，把桌面留给手头的事。BiliDanmu 可以播放 B 站视频的音频，按分 P、合集或列表接着听，并显示视频原有字幕与评论。

在主窗口左上角点击模式切换，选择「听视频」。侧栏会显示「搜索视频」「收藏夹」「稍后再看」和「正在播放」。

## 从 BV 号或链接开始

打开「收藏夹」页，在顶部输入框粘贴 BV 号或视频链接，点击「播放」，也可以按 Enter。

支持的输入例如：

```text
BV1GJ411x7h7
https://www.bilibili.com/video/BV1GJ411x7h7/
```

带参数的完整视频链接也可以识别。输入中需要包含 BV 号；如果复制的是 `b23.tv` 短链接，请先在浏览器打开，再复制包含 BV 号的完整链接。

## 搜索想听的内容

进入「搜索视频」，输入歌名、UP 主或其他关键词并搜索。结果中保留封面、标题、作者与时长，点击任意一项开始听。

继续向下滚动会加载更多搜索结果。点击播放时，当前已经加载的结果会组成一个播放列表，从选中项开始顺序播放。

## 听收藏夹和稍后再看

登录后，「收藏夹」页会显示当前账号创建的收藏夹。打开一个收藏夹，点击视频即可播放；收藏夹内容较多时，可以向下滚动继续加载。

「稍后再看」会读取当前账号在 B 站保存的列表。点击任意条目即可从这里开始听，也可以点击「刷新」重新读取列表。

这两个入口用于浏览和播放。需要添加、移除视频或整理收藏夹时，请在 B 站完成操作，再回到 BiliDanmu 刷新相应列表。

## 播放列表如何接着听

| 播放来源 | 列表中的内容 |
| --- | --- |
| BV 号 / 视频链接 | 当前视频的各个分 P；只有一 P 时就是一首 |
| 收藏夹 | 点击播放时，已经加载的收藏夹视频 |
| 搜索结果 | 点击播放时，已经加载的搜索结果 |
| 稍后再看 | 本次读取到的稍后再看列表 |
| 合集 | 当前视频所属合集中的条目 |

在播放器中，如果当前视频有多个分 P 或属于合集，可以打开列表切换菜单，选择「分 P」或对应合集。

从收藏夹或搜索结果开始播放时，列表按视频排列，通常播放每个视频的第一 P。想连续听同一视频的全部分 P，请切换到该视频的「分 P」列表。稍后再看会优先使用列表记录中的分 P 信息。

「设置 → 听视频 → 自动连播」控制一首结束后是否继续下一首。开启时顺序播放到列表末尾后停止；关闭时当前曲目结束就停止。分页列表只包含开始播放时已经加载的内容，后续新加载的条目不会自动补入正在播放的列表；加载更多后，可以重新选择条目来建立新的列表。

## 播放控制与底部小播放条

播放器底部可进行以下操作：

- 播放或暂停，切换上一首、下一首。
- 拖动进度条跳转位置。
- 调整音量。
- 打开评论，或在有分 P / 合集时切换列表。

离开播放页去浏览搜索结果、收藏夹或其他页面，声音仍然继续。主窗口底部会出现小播放条，显示当前曲目，并提供播放、暂停、切曲和停止按钮。点击曲目名称，或侧栏的「正在播放」，可以回到完整播放器。

小播放条是主窗口的一部分。点击它的关闭按钮会停止播放并清空当前播放状态。

## 跟随视频原有字幕

播放器会读取视频已有的字幕轨，并高亮正在播放的句子。点击任意一句，就能跳到该句的开始时间。

默认视图保留视频封面和字幕区。点击「专注字幕」可以扩大阅读区域，再点「返回封面」切回。

开启自动跟随后，当前字幕会保持在阅读区中间。你也可以用鼠标滚轮向前翻阅；手动浏览会暂时停止跟随，3 秒后自动恢复，或点击「跟随」立即回到当前句。

在「设置 → 听视频」中可以调整：

- 字幕字号。
- 是否自动跟随播放。
- 是否显示每句开始时间。
- 默认使用「封面与字幕」还是「专注字幕」视图。

字幕取决于视频是否提供可读取的字幕轨。没有字幕时，仍然可以听音频和查看评论；读取失败时可点击「重新加载」。当前自动使用第一条字幕轨，没有语言切换入口。

## 看评论、发回复

在播放器底部点击「评论」，可按点赞数或发布时间排序，向下浏览更多评论，并展开楼中楼回复。

登录后可以点赞或取消点赞、发表新评论。点击一条评论可进入回复状态，在输入框中写好内容后点击「发布」；点击输入框外的暗色区域可以取消回复。

右键点击评论可以复制整段内容。匿名模式下可以浏览评论，点赞、发布和回复需要登录。

## 调整播放偏好

打开「设置 → 听视频」可以设置启动时默认音量和自动连播。听视频音量与直播音量分别设置；在播放器临时调节音量，不会改动默认值。调整完成后点击「保存设置」。

如果遇到无法播放的内容，可以先检查视频是否仍可访问、账号是否需要登录或重新授权，再重新打开。收藏夹和稍后再看属于账号内容，请确认已经切换到保存这些内容的账号。
