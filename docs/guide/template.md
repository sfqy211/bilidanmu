# 消息模板

BiliDanmu 支持消息模板功能，方便你复用常用的弹幕内容。

## 功能入口

在弹幕窗口中点击剪贴板按钮，打开「消息模板」面板。

## 操作

| 操作 | 说明 |
| --- | --- |
| 创建模板 | 输入标题与内容，保存为模板 |
| 编辑模板 | 修改已有模板的标题或内容 |
| 删除模板 | 移除不再需要的模板 |

## 使用场景

- **常用话术**：保存开场白、感谢语、引导语等
- **活动文案**：保存直播活动宣传文案
- **快捷发送**：从模板快速选择并发送，无需重复输入

## 与自动发送配合

消息模板可与自动发送功能配合使用：

1. 创建多条消息模板
2. 在消息模板面板中选择模板内容加载到输入框
3. 结合自动发送功能循环发送
