# 自动发送与点赞

BiliDanmu 提供自动发送弹幕与自动点赞功能，帮助你在直播互动中更高效。

## 自动发送

### 功能入口

在弹幕窗口中打开「自动发送」面板。

### 三个 Tab

| Tab | 说明 |
| --- | --- |
| 文字 | 自定义多条文字弹幕，按顺序循环发送 |
| 表情 | 选择表情弹幕循环发送 |
| 点赞 | 设置点赞参数，批量自动点赞 |

### 参数设置

- **发送间隔**：可设置每次发送之间的时间间隔（秒）
- **时间限制**：可选设置自动发送的总时长
- **切房自动停止**：切换房间时自动停止当前自动发送任务

### 使用流程

1. 选择 Tab（文字 / 表情 / 点赞）
2. 添加或选择要发送的内容，或设置点赞参数
3. 设置发送间隔与时间限制
4. 点击「开始」
5. 可随时「停止」

## 自动点赞

### 功能入口

在弹幕窗口中打开「自动点赞」面板。

### 参数设置

| 参数 | 说明 |
| --- | --- |
| 目标数 | 本次自动点赞的总目标数 |
| 批次 | 每批点赞的数量 |
| 间隔 | 每批之间的时间间隔（秒） |

### 使用流程

1. 设置目标数、批次、间隔
2. 点击「开始」
3. 可随时「停止」

## 注意事项

- 自动发送与点赞功能请合理使用，避免违反 B 站社区规范
- 过高的发送频率可能导致账号被禁言
- 建议设置合理的间隔时间
