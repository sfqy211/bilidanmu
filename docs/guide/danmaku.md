# 弹幕收发

弹幕是 BiliDanmu 的核心功能。本章介绍如何发送与接收弹幕。

## 实时接收

BiliDanmu 通过 **WebSocket 长连接** 实时接收直播间消息，包括：

- **弹幕**：普通文字弹幕、表情弹幕
- **礼物**：投喂礼物、连击礼物
- **进场**：用户进入直播间
- **醒目留言**：付费高亮消息，真实颜色还原
- **上舰**：开通大航海

## 发送弹幕

### 文字弹幕

1. 在弹幕输入框输入文字
2. 按回车或点击发送按钮
3. 弹幕会使用当前选中的账号发送

### 表情弹幕

1. 点击表情按钮打开表情面板
2. 选择表情或输入 `[表情名]`
3. 发送后自动渲染为图片

## 弹幕渲染

- **内联表情**：`[微笑]` 等标签自动替换为表情图片
- **醒目留言**：两段式卡片 + 背景图，还原真实颜色
- **头像与昵称**：支持显示发送者头像与昵称
- **图片代理**：通过本地代理加载图片，绕过 CDN Referer 防盗链

## 弹幕过滤

可在设置中配置：

- 按关键词过滤
- 按用户过滤
- 按消息类型过滤（仅看弹幕 / 仅看礼物等）

## 常见问题

**Q：弹幕发送失败？**

A：请检查账号是否登录、是否被禁言、或网络连接是否正常。

**Q：弹幕延迟较高？**

A：WebSocket 连接通常是实时的，延迟过高请检查网络状况。
