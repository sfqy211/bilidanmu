# 弹幕收发

弹幕是 BiliDanmu 的核心功能。本章介绍如何发送与接收弹幕。

## 实时接收

BiliDanmu 通过 **WebSocket 长连接** 实时接收直播间消息，包括：

- **弹幕**：普通文字弹幕、表情弹幕
- **礼物**：投喂礼物、连击礼物（兼容新旧两种礼物协议，含 B 站新版 protobuf 格式）
- **进场**：用户进入直播间
- **醒目留言**：付费高亮消息，真实颜色还原
- **上舰**：开通大航海
- **点赞**：点赞消息与总点赞数
- **直播状态**：开播 / 下播提示、开播时长、在线人数、累计看过人数
- **标题变更**：主播直播中修改标题，弹幕窗标题栏即时跟随

## 发送弹幕

### 文字弹幕

1. 在弹幕输入框输入文字
2. 按回车或点击发送按钮
3. 弹幕会使用当前选中的账号发送

> 输入法选词期间的回车不会误发送；输入内容上限 40 字，拼音组合中允许暂时超出、上屏后自动截断。

### 表情弹幕

1. 点击表情按钮打开表情面板
2. 选择表情或输入 `[表情名]`
3. 发送后自动渲染为图片

## 弹幕渲染

- **内联表情**：`[微笑]` 等标签自动替换为表情图片
- **醒目留言**：两段式卡片 + 背景图，还原真实颜色
- **头像与昵称**：支持显示发送者头像与昵称
- **图片代理**：通过本地代理加载图片，绕过 CDN Referer 防盗链

## 弹幕过滤

- 按关键词或用户屏蔽（设置或弹幕窗的屏蔽面板中配置，对所有直播间生效）
- 礼物栏按类型与电池数量筛选
- 活动栏选择显示全部、只看进场或只看点赞，也可隐藏活动栏
- 表情可显示为图片、文字或整体隐藏

## 常见问题

**Q：弹幕发送失败？**

A：请检查账号是否登录、是否被禁言、或网络连接是否正常。

**Q：弹幕延迟较高？**

A：WebSocket 连接通常是实时的，延迟过高请检查网络状况。
