# 窗口与 Dock

BiliDanmu 提供丰富的窗口与桌面集成功能，打造原生桌面体验。

## 系统托盘

- **单击托盘图标**：切换当前窗口显示 / 隐藏
- **右键菜单**：
  - 切换房间
  - 切换账号
  - 退出应用

> **提示**：当前窗口指弹幕窗口（房间已连接时）或主窗口（未连接房间时）。

## 窗口 Dock 折叠

把弹幕窗拖到屏幕左侧、右侧或顶部边缘，它会自动收成一条细边条：

- **展开**：鼠标靠近边条时，窗口完整展开；移开后自动收回
- **退出**：展开后把窗口拖离屏幕边缘，恢复自由窗口；收起速度可在设置中调整（快 / 标准 / 慢 / 关闭）
- 顶部吸附收为水平细条，左右吸附收为垂直细条

## 仅输入框模式

点标题栏的「仅输入框模式」按钮（`TextCursorInput` 图标），整个弹幕窗缩为一条输入栏：

- 只保留输入框、发送按钮、表情按钮、恢复按钮和拖动竖条
- 进入时若贴边吸附会先解除吸附；紧凑模式下不再触发吸附，恢复完整窗口后自动恢复可吸附
- 进出模式时窗口**底边锚定**：紧凑栏正好落在原输入栏的位置，不会跳到窗口顶部
- 点击表情按钮临时展开表情面板（360×400），选择表情发送后自动收起；面板期间拖动过窗口，收起后位置保留
- 模式与位置持久化，重启应用后保持；宽度沿用完整窗口宽度，可拖边缘在 240–520 逻辑像素内调整

## 窗口透明度

- 支持 **10–100%** 背景不透明度调节
- 全局背景跟随主题
- 适合需要边工作边看弹幕的场景

## 透传模式

- 开启后，窗口非交互区域 **点击穿透**
- 仅交互元素（按钮、输入框等）响应鼠标事件
- 适合需要透过窗口操作其他应用的场景

## 标题栏按钮管理

弹幕窗口标题栏上的按钮支持按需隐藏：

- 进入 **设置 → 弹幕窗口 → 标题栏按钮**，以图标网格形式列出全部可配置按钮：置顶、锁定位置、仅输入框模式、窗口透传、房间切换、隐藏到托盘
- 点击图标即切换该按钮在标题栏的显示，改动即时生效并保存
- **退出直播间按钮固定保留**，不开放隐藏——它是唯一可靠的断开连接入口
- 旧版本数据升级后所有按钮保持显示

## 自定义标题栏

- 无原生窗口装饰
- 全部窗口统一风格
- 支持最小化、最大化、关闭

## 窗口持久化

- 自动保存窗口位置与尺寸（位置为物理像素、尺寸为逻辑像素，防抖落盘）
- 下次启动恢复上次的窗口几何；仅输入框模式与完整模式的尺寸分别记忆
- 保存的坐标不在任何显示器内时（拔线、改布局），自动回退系统默认定位

## 多窗口

BiliDanmu 包含以下窗口：

| 窗口 | 标签 | 说明 |
| --- | --- | --- |
| 主窗口 | `main` | 房间列表、账号管理、设置等 |
| 弹幕窗口 | `danmaku` | 实时弹幕显示与发送，常驻窗口，切房时原地切换内容 |
| 抽屉窗口 | `drawer-{roomId}-{panel}` | 侧边抽屉面板 |

## 窗口互斥

弹幕窗口与主窗口互斥：

- 进入房间时隐藏主窗口
- 退出房间（真实断开）时恢复主窗口
- 关闭弹幕窗口仅隐藏到托盘，房间仍保持连接

## 快捷键

全部快捷键可在 **设置 → 快捷键** 中自定义、清除（停用）或恢复默认；同一组合不允许绑定到两个动作，注册失败（如被其他程序占用）会在设置页提示。

### 全局快捷键

任何应用在前台时都能触发：

| 动作 | 默认绑定 | 说明 |
| --- | --- | --- |
| 显示 / 隐藏应用窗口 | `Ctrl+Alt+D` | 与托盘左键单击同语义：连接房间时切换弹幕窗，否则切换主窗口 |
| 仅输入框模式 | `Ctrl+Alt+B` | 弹幕窗进入 / 退出仅输入框紧凑模式 |
| 音频播放 / 暂停 | 未绑定 | 控制直播间音频流 |
| 音频静音 | 未绑定 | 静音 / 恢复直播间音频 |

### 应用内快捷键

仅在应用窗口内生效：

| 动作 | 默认绑定 |
| --- | --- |
| 界面放大 | `Ctrl+=` |
| 界面缩小 | `Ctrl+-` |
| 重置界面缩放 | `Ctrl+0` |
| 弹幕字号 | `Ctrl + 滚轮` |

`Enter` 发送、`Esc` 关闭弹层、`↑` 输入历史属于输入框惯例键，固定不可改。

> **提示**：全局快捷键在应用启动与每次保存设置时重新注册；隐藏窗口期间音频不受影响（已禁用 WebView2 的后台节流）。
