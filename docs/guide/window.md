# 窗口与 Dock

BiliDanmu 提供丰富的窗口与桌面集成功能，打造原生桌面体验。

## 系统托盘

- **单击托盘图标**：切换当前窗口显示 / 隐藏
- **右键菜单**：
  - 切换房间
  - 切换账号
  - 退出应用

> **提示**：当前窗口指弹幕窗口（房间已连接时）或主窗口（未连接房间时）。

## 窗口 Dock 折叠

BiliDanmu 支持将窗口折叠为侧边小条，节省桌面空间：

- **展开**：窗口正常显示
- **折叠**：窗口收缩为侧边小条，仅显示关键信息
- **退出**：关闭窗口

折叠状态可通过 `dock_expand`、`dock_collapse`、`dock_exit` 等命令控制。

## 窗口透明度

- 支持 **0–100%** 透明度调节
- 全局背景跟随主题
- 适合需要边工作边看弹幕的场景

## 透传模式

- 开启后，窗口非交互区域 **点击穿透**
- 仅交互元素（按钮、输入框等）响应鼠标事件
- 适合需要透过窗口操作其他应用的场景

## 自定义标题栏

- 无原生窗口装饰
- 全部窗口统一风格
- 支持最小化、最大化、关闭

## 窗口持久化

- 自动保存窗口大小
- 下次启动恢复上次的窗口尺寸

## 多窗口

BiliDanmu 包含以下窗口：

| 窗口 | 标签 | 说明 |
| --- | --- | --- |
| 主窗口 | `main` | 房间列表、账号管理、设置等 |
| 弹幕窗口 | `danmaku-{roomId}` | 实时弹幕显示与发送，运行时动态创建 |
| 抽屉窗口 | `drawer-{roomId}-{panel}` | 侧边抽屉面板，当前支持 `ai` 面板 |

## 窗口互斥

弹幕窗口与主窗口互斥：

- 进入房间时隐藏主窗口
- 退出房间（真实断开）时恢复主窗口
- 关闭弹幕窗口仅隐藏到托盘，房间仍保持连接

## 快捷键

可在设置中配置全局快捷键，例如：

- 显示 / 隐藏弹幕窗口
- 切换房间
- 切换账号
