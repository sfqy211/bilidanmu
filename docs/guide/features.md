# 功能总览

BiliDanmu 围绕 B 站直播的核心场景，提供以下功能模块。

## 账号与登录

- **多账号管理**：支持添加、切换、移除多个 B 站账号
- **TV 二维码登录**：使用 B 站 TV 端二维码登录
- **自动恢复**：启动时自动恢复上次登录状态
- **快速切换**：弹幕窗口内一键切换发送账号
- **匿名账号**：支持切换到匿名账号发送弹幕
- **Cookie 刷新**：支持手动刷新 Cookie 延长有效期

## 房间搜索

- 支持 **主播名 / 房间号 / 链接 / UID** 多种搜索方式
- 本地 **SQLite** 持久化搜索历史与常用房间
- 搜索结果快速进入直播间
- 房间列表实时显示开播状态

## 弹幕收发

- **实时接收**：WebSocket 长连接，接收弹幕、礼物、进场、醒目留言、上舰
- **文字弹幕**：自定义文字发送，支持颜色、模式、字号
- **表情弹幕**：`[表情名]` 内联渲染为图片，支持大表情
- **醒目留言**：真实颜色还原，两段式卡片 + 背景图
- **点赞数 / 在线人数**：实时更新显示

## 自动发送与点赞

- **自动发送**：文字 / 表情两个 Tab
  - 可调发送间隔
  - 可选时间限制
  - 切换房间自动停止
- **自动点赞**：批量点赞，可调目标数 / 批次 / 间隔
- **消息模板**：支持创建、编辑、删除消息模板，方便复用常用弹幕内容

## 直播播放

- 实时直播 **音频流** 播放
- v2 API 获取直播流地址
- 本地代理绕过 CORS
- mpegts.js 解码 FLV → fMP4 → MSE 播放
- 支持画质选择

## 语音转字幕（STT）

- 基于 **sherpa-onnx** 流式识别
- 本地推理，无需联网
- 字幕叠加层实时显示
- 支持切换模型、调节同步延迟
- 可在设置中开启 / 关闭

## AI 助手

- 对接 **AstrBot** 框架
- 多条回复选项
- 自定义输入
- 自动总结直播内容
- 记忆学习
- 独立 AI 窗口

## 窗口与桌面

- **系统托盘**：单击切换窗口可见性，右键菜单切换房间 / 账号
- **窗口 Dock 折叠**：窗口可折叠为侧边小条，节省桌面空间
- **透明度调节**：0–100%，全局背景跟随主题
- **透传模式**：点击穿透，仅交互元素响应
- **自定义标题栏**：无原生装饰，全部窗口统一风格
- **开播时长**：实时显示（v2 API 获取直播时间戳，自动刷新）
- **窗口持久化**：自动保存窗口大小

## 图片代理与缓存

- **SSRF 白名单**：防止恶意请求
- **LRU 缓存**：减少重复下载
- 绕过 CDN Referer 防盗链
- 支持查看缓存统计、清除缓存

## 更新检查

- 自动检查 GitHub 最新版本
- 显示更新日志
- 支持下载更新包
