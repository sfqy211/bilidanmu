# 设计风格

BiliDanmu 的视觉设计追求 **简洁、现代、一致**，同时融入 B 站品牌元素。

## 设计理念

- **简洁**：去除冗余装饰，突出核心内容
- **现代**：采用现代设计语言，如圆角、阴影、渐变
- **一致**：全部窗口统一风格，提供连贯体验
- **可读**：弹幕等高信息密度内容优先保证可读性

## 阴影

| 名称 | 值 | 用途 |
| --- | --- | --- |
| sm | `0 1px 2px rgba(0,0,0,0.05)` | 轻微浮起 |
| md | `0 4px 12px rgba(0,0,0,0.08)` | 卡片 |
| lg | `0 8px 24px rgba(0,0,0,0.12)` | 弹窗 |

## 动效

- **过渡时长**：150ms（默认）、250ms（复杂）
- **缓动函数**：`cubic-bezier(0.4, 0, 0.2, 1)`
- **原则**：动效应快速、自然，不打扰用户
