# 设计风格

BiliDanmu 的视觉设计追求 **克制、精致、可靠**，整体是干净专业工具风，而不是"个人开发小玩具"。

## 设计理念

- **摸鱼优先**：非弹幕页面默认是低显眼度工作台——紧凑行高（约 36px）、13px 级小字号、低饱和、无大图
- **内容即界面**：封面、标题、状态是主角，容器与装饰退后
- **Token 先行**：颜色、间距、圆角全部走语义变量，不写魔法色值
- **明暗同权重**：每个颜色 token 成对定义，改任何页面两个模式都要过一遍
- **动效克制**：只用于状态变化（淡入、缓出 quart/expo），无弹跳无光泽
- **弹幕页例外**：完全对齐 B 站直播姬的密度与风格，是功能基准

设计语境全文见仓库根目录 [`.impeccable.md`](https://github.com/sfqy211/bilidanmu/blob/main/.impeccable.md)。

## 字体

| 用途 | 字体 |
| --- | --- |
| 界面（默认） | `"Segoe UI", "Microsoft YaHei", system-ui, sans-serif` |
| 微软雅黑 | `"Microsoft YaHei", "Segoe UI", sans-serif` |
| 等线 | `DengXian, "Microsoft YaHei", sans-serif` |
| 宋体 | `SimSun, "Songti SC", serif` |
| 数字 | `numeric` 类（等宽数字，避免跳动） |

内容字体可以独立于界面字体，「与界面字体相同」是默认值。

## 间距

基于 4px 网格：`4 / 8 / 12 / 16 / 24 / 32`。

## 圆角

| 名称 | 值 | 用途 |
| --- | --- | --- |
| 窗口 | `8px` | 所有窗口统一圆角（`.window-rounded`） |
| `--radius` | `0.875rem`（14px） | Tailwind `rounded-lg` |
| `md` | 12px | 按钮、卡片 |
| `sm` | 10px | 小元素 |
| `full` | 胶囊 | 标签、胶囊按钮 |

## 阴影

项目整体克制使用阴影，层次主要靠「页面底色 / 表面色」的明度差表达；卡片与大块区域通常只用 `border-subtle` 分隔，不叠加大阴影。

## 动效

- **过渡时长**：150ms（默认）、250ms（复杂）；吸附动画可选关闭 / 快 / 标准 / 慢 / 自定义毫秒
- **缓动函数**：`cubic-bezier(0.4, 0, 0.2, 1)`
- **原则**：动效应快速、自然，不打扰用户；系统开启「减少动态效果」时全部降级
