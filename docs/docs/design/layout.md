# 页面布局

BiliDanmu 的页面布局遵循统一的设计规范，确保全部窗口风格一致。

## 主窗口外壳

```
┌────────────────────────────────────────────────┐
│ TitleBar   BiliDanmu        ─   □   ✕          │  40px
├────────┬───────────────────────────────────────┤
│ Side   │  页面内容（可滚动）                    │
│ bar    │                                       │
│        │                                       │
│ 直播间 │                                       │
│ 账号   │                                       │
│ AI 接入│                                       │
│ 听视频 │                                       │
│        │                                       │
│ 设置   │                                       │
│ v0.5.0 │                                       │
├────────┴───────────────────────────────────────┤
│ MiniPlayer（存在播放队列且不在播放页时）        │
└────────────────────────────────────────────────┘
```

- **TitleBar**：自定义，无原生装饰。左侧品牌图标 + 名称，右侧最小化 / 最大化 / 关闭。拖动标题栏移动窗口，双击最大化。
- **Sidebar**：默认宽度 `calc(78px + 界面字号 × 3)`（14px 字号下约 120px），可拖动右侧手柄在 88–224px 间调整；双击手柄恢复默认，方向键微调 ±8px。宽度记忆在 `selections`。底部显示匿名状态与版本号。
- **主内容区**：`PageHeader`（标题 + 可选描述 + 右侧操作）+ 内容区。列表页统一使用「悬浮行卡」视觉。
- **MiniPlayer**：固定在内容区底部，离开播放页时才出现。

## 页面头部

```tsx
<PageHeader
  title="直播间"
  description={<p>…</p>}
  actions={<div>…</div>}   // 搜索框、工具按钮、主按钮
/>
```

工具条按钮统一为 32×32 图标按钮；主操作（添加）使用带文字的胶囊按钮。

## 列表页行卡

直播间、账号、听视频、添加页共用同一套行卡：

```
┌──────────────────────────────────────────────────────┐
│ [封面/头像] 主标题            状态/时间    [操作按钮] │  ~36–52px
│             次级信息                                  │
└──────────────────────────────────────────────────────┘
```

- 行高紧凑，字号 13px 级，悬停时抬升背景
- 操作按钮默认低对比，悬停才提亮
- 危险操作（删除/移除）悬停变红

## 设置页布局

左侧是分类导航（8 个分类），右侧是表单区：

```
┌──────────────────────────────────────────────┐
│ 设置                          [重置为默认]   │
├────────────┬─────────────────────────────────┤
│ 通用       │  ┌ 分组标题 ─────────────────┐  │
│ 快捷键     │  │ 选项标题     [控件]       │  │
│ 外观       │  │ 说明文字                  │  │
│ 弹幕窗口   │  └───────────────────────────┘  │
│ 直播音频   │  ┌ 分组标题 ─────────────────┐  │
│ 听视频     │  │ …                         │  │
│ 存储       │  └───────────────────────────┘  │
│ 关于       │                                 │
└────────────┴─────────────────────────────────┘
```

每个分类的分组以卡片形式呈现；「重置为默认设置」只还原当前页涉及的字段（外观页会重置整个 `visual` 与 `appearance`，弹幕窗口页只重置弹幕相关子集）。

## 弹幕窗口布局

```
┌─────────────────────────────────────────┐
│ TitleBar 主播名 - 标题   [按钮组] [退出] │
├─────────────────────────────────────────┤
│ 控制栏  ▶ 音量 | 消息数 ¥总额 时长 在线  │
├─────────────────────────────────────────┤
│ 礼物栏  送礼 上舰 醒目留言 [电池筛选]    │
│         …礼物 / SC / 舰长消息…          │
├═════════════════════════════════════════┤  ← 可拖拽分隔
│ 弹幕栏                                   │
│         …普通弹幕…                      │
├═════════════════════════════════════════┤  ← 可拖拽（仅 scroll 模式）
│ 活动栏  全部 进场 点赞                   │
│         …进场 / 点赞…                   │
├─────────────────────────────────────────┤
│ 功能栏  ⚡ 😊 🎁 账号 屏蔽 设置 快捷消息 │
│ 输入框                           [发送] │
└─────────────────────────────────────────┘
```

- 分隔条支持指针拖拽、双击重置、方向键 ±5%
- 活动栏三态：`scroll`（可拖拽）、`latest`（固定 32px 一行）、`hidden`
- 收起条（贴边吸附）和仅输入框栏是同一套组件的形态切换
- 浮层面板（设置 / 屏蔽 / 表情 / 礼物 / 循环发送 / 快捷消息）共用 `FloatingPanel` 外壳，最大高度 50vh

## 播放页布局

```
┌──────────────────────────────────────────────┐
│ ← [封面] 标题 / UP 主 · 队列名      [列表面板]│
├──────────────────────────┬───────────────────┤
│                          │ 播放列表（可选）  │
│   字幕阅读区             │  分 P / 合集      │
│   （逐句高亮）           │                   │
│                          │                   │
├──────────────────────────┴───────────────────┤
│ 进度条 00:00 ──────────────── 03:21          │
│ 评论   ⏮  ▶  ⏭   模式  列表  音量 ───       │
└──────────────────────────────────────────────┘
```

封面缩略图可关闭（设置 → 听视频 → 显示视频封面）。

## 响应式

BiliDanmu 主要面向桌面端：

- 主窗口最小 800×600
- 弹幕窗口 240–1200 × 160–900 逻辑像素
- 侧栏在窄窗口下仍保留最小 88px，靠拖动或自动换行保持可用

## 通用组件

| 组件 | 用途 |
| --- | --- |
| `PageHeader` | 页面标题 + 描述 + 操作区 |
| `WorkspaceLayout` | 标题栏 + 侧栏 + 内容 + 迷你播放条 |
| `ProxiedImage` | 通过代理加载图片 |
| `InlineMessage` | 内联提示条（error/success/info/warning） |
| `ConfirmDialog` / `CloseDialog` / `UpdateDialog` | 对话框 |
| `FloatingPanel` | 弹幕窗浮层外壳 |
| `Select` | 自绘下拉框 |
| `SettingsGroup` / `SettingsRow` / `SettingsToggle` / `SettingsChoice` / `SettingsRange` | 设置页控件原语 |
| `DockCollapsedBar` | 吸附收起条 |
