# 页面布局

BiliDanmu 的页面布局遵循统一的设计规范，确保全部窗口风格一致。

## 布局结构

```
┌─────────────────────────────────────────┐
│              TitleBar (自定义)            │
├──────────┬──────────────────────────────┤
│          │                              │
│ Sidebar  │         Main Content         │
│          │                              │
│  - 房间   │                              │
│  - 账号   │                              │
│  - AI    │                              │
│  - 设置   │                              │
│          │                              │
└──────────┴──────────────────────────────┘
```

## 标题栏

- 自定义标题栏，无原生装饰
- 显示当前页面标题
- 窗口控制按钮（最小化、最大化、关闭）
- 全部窗口统一风格

## 侧边栏

- 固定宽度（约 200px）
- 导航菜单
- 可折叠

## 主内容区

- 自适应宽度
- 根据页面内容滚动

## 弹幕窗口布局

```
┌─────────────────────────────────────────┐
│              TitleBar                    │
├─────────────────────────────────────────┤
│                                         │
│            Danmaku List                 │
│            (虚拟滚动)                    │
│                                         │
├─────────────────────────────────────────┤
│   AccountSwitcher  │  Input  │  Send    │
└─────────────────────────────────────────┘
```

## 设置页面布局

```
┌─────────────────────────────────────────┐
│  Sidebar (设置分类)  │  Content (表单)   │
│  - 常规             │                   │
│  - 弹幕             │                   │
│  - 账号             │                   │
│  - 直播             │                   │
│  - STT              │                   │
│  - AI               │                   │
└─────────────────────────────────────────┘
```

## 响应式

BiliDanmu 主要面向桌面端，但仍需考虑：

- 窗口最小宽度：800px
- 窗口最小高度：600px
- 侧边栏可折叠以适应较小窗口

## 通用组件

| 组件 | 用途 |
| --- | --- |
| `PageTabs` | 页面内 Tab 切换 |
| `ProxiedImage` | 通过代理加载图片 |
| `InlineMessage` | 内联消息提示 |
| `TitleBar` | 自定义标题栏 |
| `AppSidebar` | 应用侧边栏 |
| `SplitLayout` | 分栏布局 |
