# 听视频

把视频的声音留在耳边，把桌面留给手头的事。BiliDanmu 可以把 B 站视频当音乐听，按分 P、合集或列表接着听，并显示视频原有字幕与评论。

点击左侧导航的「听视频」进入。页面是一个「收藏」列表，标题右侧有「刷新」按钮；列表第一行是「稍后再看」，后面依次是当前账号创建的收藏夹。每行显示名称与视频数。

右上角「添加视频」进入搜索子页。

## 从 BV 号或链接开始

点击「添加视频」，把模式切到「BV 号/链接」，粘贴内容后搜索：

```text
BV1GJ411x7h7
https://www.bilibili.com/video/BV1GJ411x7h7/
```

带参数的完整视频链接也可以识别——只要输入里含有 BV 号即可，搜索结果会出现一条待确认的条目，点击播放按钮开始听。如果复制的是 `b23.tv` 短链接，请先在浏览器打开，再复制包含 BV 号的完整链接。

## 搜索想听的内容

在「添加视频」页（默认「视频名称」模式）输入歌名、UP 主或其他关键词并搜索。结果保留封面、标题、作者与时长，点击播放按钮开始听。搜索结果页不支持滚动加载更多，换关键词重新搜索即可。

搜索结果不会组成播放队列：点进某一条后，播放器按**这个视频的各个分 P** 建队列（只有一 P 时就是一首）。想听一串视频，请用收藏夹或稍后再看。

## 听收藏夹和稍后再看

登录后，「听视频」首页会列出当前账号创建的收藏夹。点开一个收藏夹，页面顶部显示「共 N 个视频」「播放全部」与「刷新」：

- **点某一行**：以当前已加载的视频（滚动加载出来的部分）建立队列，从该条开始听
- **点「播放全部」**：先把整个收藏夹拉全，再从第一首开始听

「稍后再看」的行为基本相同，区别是它一次全量返回，所以单点某条也等于用整个列表建队列。

匿名模式下列表为空，需要先登录。这两个入口都只用于浏览和播放——需要添加、移除视频或整理收藏夹时，请在 B 站完成操作，再回到 BiliDanmu 刷新列表。

## 播放队列如何接着听

| 播放来源 | 队列内容 |
| --- | --- |
| BV 号 / 视频链接 / 搜索结果 | 当前视频的各个分 P；只有一 P 时就是一首 |
| 收藏夹 | 点某行时已加载的全部视频；「播放全部」拉全 |
| 稍后再看 | 本次读取到的稍后再看列表 |
| 合集 | 当前视频所属合集中的条目 |

播放页右侧可以展开「播放列表」面板：它按队列顺序列出曲目，展开当前视频的分 P 子节点，并列出一个「合集」分支——点击合集里的某一集会用合集重建队列。

从收藏夹或稍后再看开始播放时，队列按视频排列，通常播放每个视频的第一 P。想连续听同一视频的全部分 P，请在列表面板里展开它的分 P。

「设置 → 听视频 → 自动连播」控制一首结束后是否继续下一首。开启时顺序播放到队列末尾后停止；关闭时当前曲目结束就停止。播放模式按钮可在「顺序 / 随机 / 单曲循环 / 列表循环」间切换，该选择只在本次会话内有效。

## 播放控制与底部小播放条

播放页底部提供：

- 播放或暂停，切换上一首、下一首。
- 拖动进度条跳转位置。
- 播放模式切换、展开/收起播放列表。
- 调整「听视频」音量（与直播间音频共用全局音量）。
- 「评论」按钮进入该视频的评论区。

离开播放页去浏览搜索结果、收藏夹或其他页面，声音仍然继续。主窗口底部会出现迷你播放条，显示封面（可在设置里关闭）、当前曲目与队列名，提供上一首、播放/暂停、下一首和停止按钮。点击曲目名称可以回到完整播放器。

迷你播放条在播放页自身不显示；点它的停止按钮会停止播放并清空当前队列。

进入直播间时视频音频会自动暂停（队列与进度保留），离开直播间后也不会自动恢复——需要手动点播放。

## 跟随视频原有字幕

播放页以字幕为阅读主体，顶部是返回按钮、封面缩略图（可在设置里关闭）和标题，下面是整块字幕阅读区。

播放器会读取视频已有的字幕轨并高亮正在播放的句子，点击任意一句即可跳到该句开始时间。

开启「自动跟随播放」后，当前字幕会保持在阅读区中间。用滚轮、拖动或方向键手动浏览都会暂停跟随，3 秒后自动恢复；也可以点字幕头部的「跟随」按钮立即回到当前句。

在「设置 → 听视频」中可以调整：

- 字幕字号（14–24px）。
- 是否自动跟随播放。
- 是否在每句旁显示开始时间。
- 是否在列表、播放页标题旁和迷你播放条显示视频封面。

字幕取决于视频是否提供可读取的字幕轨。没有字幕时仍可听音频、看评论；读取失败时出现「重新加载」按钮。当前自动使用第一条字幕轨，没有语言切换入口。

## 看评论、发回复

在播放页底部点「评论」进入评论区：可按「按点赞」或「按时间」排序，向下滚动加载更多，点「N 条回复」展开楼中楼。

登录后可以点赞或取消点赞、发表新评论。点击一条评论可进入回复状态，在底部输入框写好内容后点「发布」；点击输入框外的暗色区域可以取消回复。

右键点击评论可以复制整段内容。匿名模式下可以浏览评论，点赞、发布和回复需要登录。

## 调整播放偏好

打开「设置 → 听视频」：

| 分组 | 选项 |
| --- | --- |
| 播放 | 自动连播 |
| 字幕 | 字幕字号、自动跟随播放、显示时间标记 |
| 视频封面 | 显示视频封面 |

听视频与直播共用**全局音量**（「设置 → 直播音频」中的全局音量）：在弹幕窗、播放器或设置页任一处调节音量，其他位置即时联动并自动保存。

如果遇到无法播放的内容，可以先检查视频是否仍可访问、账号是否需要登录或重新授权，再重新打开。收藏夹和稍后再看属于账号内容，请确认已经切换到保存这些内容的账号。
