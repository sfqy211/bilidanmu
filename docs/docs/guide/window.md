# 窗口与 Dock

BiliDanmu 提供丰富的窗口与桌面集成功能，打造原生桌面体验。

## 系统托盘

- **单击托盘图标**：显示 / 隐藏当前窗口（连接房间时是弹幕窗，否则是主窗口）
- **右键菜单**：
  - **账号**：已登录账号列表，带勾选标记，点击即切换
  - **直播间**：只列正在直播的已保存房间（最多 10 项），格式为「主播 · 标题」
  - **退出**：停止自动任务、断开连接、保存窗口几何后退出

> **提示**：直播状态来自 60 秒轮询缓存；首次拉取成功前，菜单会退回列出全部已保存房间。

## 侧边吸附收起

把弹幕窗拖到屏幕左侧、右侧或顶部边缘（距边缘 12px 内）并松手，它会自动收成一条细边条：

- 收起条基准宽 14 逻辑像素，长度 150 物理像素，垂直/水平居中于窗口原位置
- **展开**：鼠标靠近边条时窗口完整展开；光标移出后约 250ms 自动收回
- **退出**：展开后把窗口拖离屏幕边缘（超过 28px 的滞回阈值），恢复自由窗口
- 顶部吸附收为水平细条，左右吸附收为垂直细条；底边不吸附
- 吸附动画可在设置里选「关闭 / 快 / 标准 / 慢」，也可自定义毫秒数
- 「显示收起条」关闭后，收缩态不绘制任何可见内容，但鼠标移到该位置仍能展开

## 仅输入框模式

点标题栏的「仅输入框模式」按钮（`TextCursorInput` 图标），整个弹幕窗缩为一条输入栏：

- 高度固定 48 逻辑像素，宽度沿用完整窗口宽度，可拖边缘在 240–520 之间调整
- 只保留输入框、发送按钮、表情按钮、恢复按钮和拖动竖条
- 进入时若贴边吸附会先解除吸附；紧凑模式下不再触发吸附，恢复完整窗口后自动恢复可吸附
- 进出模式时窗口**底边锚定**：紧凑栏正好落在原输入栏的位置，不会跳到窗口顶部
- 点击表情按钮临时展开表情面板（360×400），选择表情发送后自动收起；面板期间拖动过窗口，收起后位置保留
- 模式与宽度持久化，重启应用后保持
- 可用全局快捷键 `Ctrl+Alt+B` 随时进出

## 窗口透明度

- 支持 **10–100%** 背景不透明度调节
- 全局背景跟随主题
- 适合需要边工作边看弹幕的场景

## 透传与隐身

**透传模式**：

- 开启后，窗口非交互区域 **点击穿透**
- 仅带 `data-interactive` 的元素（按钮、输入框、菜单等）响应鼠标事件
- 适合需要透过窗口操作其他应用的场景

**隐身模式**：

- 开启后窗口内容淡出为全透明，并对鼠标完全透明
- 光标在窗口内停留超过 140ms 才淡入并恢复交互（快速划过不触发）
- 光标离开窗口边缘 8px 并持续 260ms 后重新隐身
- 与透传可同时开启；切换仅输入框模式会强制显形

## 标题栏按钮管理

弹幕窗口标题栏上的按钮支持按需隐藏：

- 标题栏从左到右：置顶、锁定位置、仅输入框模式、窗口透传、隐身、隐藏到托盘、房间切换、退出直播间
- 进入 **设置 → 弹幕窗口 → 标题栏按钮**，以图标网格形式列出全部可配置按钮，点击即切换显示，改动即时生效并保存
- **退出直播间按钮固定保留**，不开放隐藏——它是唯一可靠的断开连接入口
- 旧版本数据升级后所有按钮保持显示

## 自定义标题栏

- 无原生窗口装饰
- 全部窗口统一风格
- 主窗口支持最小化、最大化/还原、关闭；关闭行为可配置（询问 / 隐藏到托盘 / 退出）

## 窗口持久化

- 自动保存弹幕窗口位置与尺寸（位置为物理像素、尺寸为逻辑像素，防抖落盘）
- 下次启动恢复上次的窗口几何；仅输入框模式与完整模式的尺寸分别记忆
- 保存的坐标不在任何显示器内时（拔线、改布局），自动回退系统默认定位

## 多窗口

BiliDanmu 包含以下窗口：

| 窗口 | 标签 | 说明 |
| --- | --- | --- |
| 主窗口 | `main` | 房间列表、账号、听视频、设置等，960×680（最小 800×600） |
| 弹幕窗口 | `danmaku` | 实时弹幕显示与发送，常驻窗口，切房时原地切换内容，不占任务栏 |

弹幕窗口关闭时是隐藏到托盘，不是销毁；切房也复用同一个窗口。

## 窗口互斥

弹幕窗口与主窗口互斥：

- 进入房间时隐藏主窗口
- 退出房间（真实断开）时恢复主窗口
- 关闭弹幕窗口仅隐藏到托盘，房间仍保持连接
- 静默启动时主窗口不显示，只在托盘常驻

## 快捷键

全部快捷键可在 **设置 → 快捷键** 中自定义、清除（停用）或恢复默认；同一组合不允许绑定到两个动作，注册失败（如被其他程序占用）会在设置页提示。

### 全局快捷键

任何应用在前台时都能触发：

| 动作 | 默认绑定 | 说明 |
| --- | --- | --- |
| 显示 / 隐藏应用窗口 | `Ctrl+Alt+D` | 与托盘左键单击同语义：连接房间时切换弹幕窗，否则切换主窗口 |
| 仅输入框模式 | `Ctrl+Alt+B` | 弹幕窗进入 / 退出仅输入框紧凑模式 |
| 音频播放 / 暂停 | 未绑定 | 控制直播间音频流 |
| 音频静音 | 未绑定 | 静音 / 恢复直播间音频 |

### 应用内快捷键

仅在应用窗口内生效：

| 动作 | 默认绑定 |
| --- | --- |
| 界面放大 | `Ctrl+=` |
| 界面缩小 | `Ctrl+-` |
| 重置界面缩放 | `Ctrl+0` |
| 弹幕字号 | `Ctrl + 滚轮` |

`Enter` 发送弹幕、`Esc` 关闭对话框与下拉框属于固定惯例键。

> **提示**：全局快捷键在应用启动与每次保存设置时重新注册；隐藏窗口期间音频不受影响（已禁用 WebView2 的后台节流）。
