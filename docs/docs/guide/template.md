# 快捷消息模板

BiliDanmu 支持消息模板功能，方便你复用常用的弹幕内容。面板标题为「快捷消息」。

## 功能入口

在弹幕窗功能栏点击剪贴板图标（`快捷消息`；紧凑模式下收进 `+` 菜单）。

## 操作

| 操作 | 说明 |
| --- | --- |
| 创建模板 | 填写消息内容（最多 40 字）并保存 |
| 编辑模板 | 修改已有模板的内容 |
| 删除模板 | 移除不再需要的模板 |
| 填入发送栏 | 点模板行右侧的填充图标，内容立即写入弹幕输入框 |

模板存在本地 SQLite 的 `message_templates` 表，跨账号、跨房间共用。

## 使用场景

- **常用话术**：保存开场白、感谢语、引导语等
- **活动文案**：保存直播活动宣传文案
- **快捷发送**：从模板快速填入，无需重复输入

## 与循环发送配合

模板本身不参与自动发送，但可以这样组合：

1. 先把模板内容填入发送栏，确认措辞
2. 打开「循环发送」面板，把同样的文案按行粘贴到「文字」Tab
3. 设置间隔与限时后开始
