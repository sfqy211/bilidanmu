# 直播音频播放

BiliDanmu 支持实时直播音频流播放，让你无需打开网页即可收听直播。

## 技术原理

```mermaid
flowchart LR
    A["B 站直播流 API (v2)"] --> B["本地 HTTP 代理<br/>(绕过 CORS)"]
    B --> C["mpegts.js 解码<br/>FLV → fMP4"]
    C --> D["MSE<br/>Media Source Extensions"]
    D --> E["音频播放"]
```

## 使用方式

1. 进入目标直播间
2. 点击弹幕窗控制栏的播放按钮开始播放
3. 点击音量图标展开竖向滑杆调节音量，可暂停/停止

## 功能特点

- **纯音频流**：低带宽消耗，适合后台收听
- **v2 API**：使用 `getRoomPlayInfo`（WBI 签名 + `only_audio=1`）获取直播流地址
- **本地代理**：绕过 CORS 限制，确保流畅播放
- **mpegts.js**：将 FLV 流转换为 fMP4，通过 MSE 播放
- **全局音量**：与听视频共用同一音量，弹幕窗、播放器、设置页任一处调节即时联动并自动保存

## 连接稳定性

- **服务器优选**：连接时并发探测全部弹幕服务器，选择延迟最低的节点
- **自动重连**：连接中断后按指数退避自动重试（4s 起、30s 封顶，不设次数上限）
- **断流恢复**：播放中 5 秒无进度或 15 秒未收到新数据时自动重连（隐藏窗口、贴边收起、仅输入框模式下也不会断流——应用已禁用 WebView2 的后台节流）
- **未开播处理**：未开播时停在错误提示而不是反复重试；开启自动播放时收到开播提示会自动续播

## 开播时长

- 实时显示当前直播的开播时长
- 通过 v2 API 获取直播时间戳，并回写本地记录用于「上次直播」显示

## 相关设置

「设置 → 直播音频」：

| 分组 | 选项 |
| --- | --- |
| 直播音频 | 全局音量（0–100%）、进入直播间时自动播放音频 |
| 实时字幕 | 启用语音识别（同页，见 [语音转字幕](/guide/stt)） |

## 常见问题

**Q：播放失败或没有声音？**

A：请检查网络连接，或尝试重新进入直播间。未开播的直播间会提示无法获取音频流。

**Q：进直播间后视频音频停了？**

A：直播音频与听视频音频互斥，进入直播间会自动暂停视频（队列与进度保留），退出后可手动继续。

**Q：音画不同步？**

A：BiliDanmu 当前仅支持音频流播放，无画面输出。
