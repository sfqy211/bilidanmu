# 功能总览

BiliDanmu 围绕 B 站直播与视频音频两个场景提供以下功能。按模块分组，细节操作见对应的用户指南页面。

## 桌面与窗口

- **透明弹幕窗**：背景不透明度 10–100% 可调，透出后面的工作内容
- **贴边收起**：左侧、右侧和顶部吸附，鼠标靠近展开、移开收回，拖离边缘恢复自由窗口；收起条可整体关闭、提示线可隐藏
- **仅输入框模式**：整个弹幕窗缩为一条输入栏，只有输入框和一个把手；回车即发送，拖把手移动窗口、点把手恢复完整窗口。吸附互斥，进出时窗口底边锚定不跳动
- **点击穿透**：透过窗口的非交互区域操作桌面应用，按钮、菜单和输入栏仍可正常使用
- **隐身模式**：鼠标离开后窗口完全透明并穿透，移回时淡入，可与透传同时开启
- **置顶与锁定**：按需置顶、取消置顶或锁定位置，也可以拖动窗口和调整大小
- **标题栏按钮管理**：标题栏上除「退出直播间」外的每个按钮，都可在设置中单独显示或隐藏
- **托盘随时唤回**：单击托盘显示或隐藏当前窗口，右键切换直播间和账号；关闭弹幕窗后仍保持连接
- **记住窗口习惯**：恢复上次的窗口位置、尺寸与显示模式；主窗口关闭时可选择询问、隐藏到托盘或退出，也支持静默启动
- **界面缩放**：快捷键缩放界面、恢复默认；弹幕窗中 Ctrl + 滚轮调整弹幕字号

## 直播与消息

- **实时消息接收**：WebSocket 长连接接收文字、内联表情、大表情、礼物、醒目留言、上舰、进场和点赞，显示开播与下播提示
- **多服务器优选**：连接时并发探测全部弹幕服务器并选择延迟最低的节点，中断后自动重连
- **三栏分别查看**：礼物、弹幕和活动各有位置，拖动分隔条调整高度或收起某栏
- **自在阅读**：各栏独立跟随新消息；向上翻阅时停留在阅读位置，一键回到最新
- **直播状态一览**：在线人数、累计看过人数、点赞数、开播时长，以及本场弹幕数、礼物金额、醒目留言和上舰数
- **标题即时更新**：主播直播中修改标题或分区，弹幕窗标题栏立即跟随
- **收听直播音频**：直接播放或停止直播音频；全局音量与听视频共用，任一处调节即时联动
- **入房自动播放**：可设置进入直播间后自动播放音频；未开播时停在错误提示，收到开播提示后自动续播

## 内容与筛选

- **关键词与用户屏蔽**：添加或移除屏蔽关键词，右键屏蔽消息发送者，屏蔽设置对所有直播间生效
- **礼物筛选**：分别显示礼物、醒目留言和上舰消息，支持电池数量门槛
- **活动栏显示**：滚动列表、只看最新或隐藏活动栏，按需只看进场、点赞或全部
- **表情显示方式**：表情显示为图片或文字，也可整体隐藏；纯表情弹幕在隐藏模式下整条略过
- **用户信息显隐**：单独控制昵称、昵称颜色、荣耀等级、粉丝牌、房管标志和高能榜
- **醒目留言双重查看**：礼物栏保留完整卡片，也可在弹幕栏额外显示简化行
- **金额配色**：醒目留言与礼物共用六档金额色、大航海三档按等级配色，也可整体关闭彩色样式
- **气泡弹幕**：使用 B 站聊天气泡皮肤的用户，其弹幕按该皮肤的三段渐变色渲染背景

## 弹幕与互动

- **文字与消息操作**：输入最多 40 字弹幕回车发送，输入法选词回车不会误发；右键消息可 @ 回复、复制昵称与内容、打开用户主页、屏蔽发送者
- **表情发送与收藏**：从直播间可用表情包中选择并发送，收藏常用表情
- **整理表情包**：隐藏不常用的表情包，按账号和房间记住显示习惯
- **快捷消息模板**：创建、编辑、删除常用消息，一键填入发送栏
- **文字与表情循环发送**：多条内容按顺序循环，可设间隔和限时，进度可见，切房自动停止
- **自动点赞**：与循环发送同一个「循环发送」面板的第三个 Tab，设置目标总数、批次和间隔，随时停止

## 房间管理

- **多种方式查找**：按主播名、直播间号、直播链接或 UID 查找
- **从关注直接添加**：查看正在直播的关注列表直接加入，支持连续添加多个主播
- **封面与列表视图**：封面卡片和紧凑列表切换，按主播名、标题、房间号或 UID 筛选
- **状态分区**：直播中与未开播分区展示，各自按自定义顺序排列；可用「全部 / 直播中 / 未开播」标签筛选
- **按习惯排列**：拖动排序并记住排列，直播中的房间优先显示
- **收藏与只看收藏**：星标收藏房间，一键只看收藏，或打开收藏管理批量取消
- **时间信息**：直播中显示已播时长，未开播显示上次直播时间
- **窗口内快速切房**：弹幕窗标题栏或托盘中切换正在直播的已保存房间，不换窗口不打断

## 账号与身份

- **扫码登录**：B 站 TV 端二维码授权，启动时恢复登录状态
- **多账号管理**：添加、切换、移除多个账号，刷新头像与昵称
- **单独选择发送账号**：弹幕窗内切换发送身份，观看与收听继续使用观看账号
- **授权状态与续期**：查看授权剩余有效期，手动续期 Cookie 或重新扫码
- **匿名收听与浏览**：匿名接收弹幕和音频；发送与互动类操作需要登录

## 发现想听的视频

- **BV 号与链接直达**：输入 BV 号或粘贴含 BV 号的链接，解析后直接收听
- **关键词搜索**：按歌名、UP 主等关键词查找
- **浏览收藏夹**：查看自己账号的收藏夹并进入收听
- **听稍后再看**：读取并刷新稍后再看列表，从任意一条开始播放
- **从列表连续听**：收藏夹与稍后再看都能整表入队，「播放全部」可一次拉全收藏夹

## 播放与队列

- **完整播放控制**：播放、暂停、上一条、下一条和拖动进度
- **播放模式**：顺序、随机、单曲循环、列表循环（会话内有效）
- **分 P 与合集**：在播放列表面板展开当前视频的分 P，或切换到所属合集
- **按需自动连播**：播完继续队列下一项，或播完即停
- **页面内迷你播放条**：离开播放页继续收听，主窗口底部可暂停、切换或返回播放器
- **字幕与评论**：跟随视频原有字幕逐句高亮、点击跳转；评论按点赞或时间排列，可展开回复、点赞、发布与复制
- **与直播互斥**：进入直播间自动暂停视频音频，队列与进度保留

## 外观与阅读习惯

- **浅色与深色模式**：跟随系统或手动选择，深浅模式分别配置
- **主题预设**：深色六套（午夜 / 石墨 / 深海 / 暗夜紫 / 暖棕 / 深林），浅色六套（素纸 / 雾灰 / 晴空 / 薄荷 / 暖沙 / 樱粉），也可转为自定义
- **颜色细调**：强调色、背景、表面、前景分别设置，即时预览
- **金额档位配色**：SC 与礼物共用六档金额色，大航海三档单独取色
- **字体与字号**：界面与内容字体（系统 / 微软雅黑 / 等线 / 宋体）、字号和对比度
- **弹幕字号**：10–32px
- **动态效果**：吸附动画快/标准/慢/关闭，遵循系统「减少动态效果」
- **弹幕窗跟随背景**：可选按屏幕背景亮暗自动切换深浅

## 快捷键

- **全局快捷键**（任何应用前台时生效，可在设置 → 快捷键中自定义或停用）：
  - 显示 / 隐藏应用窗口（默认 `Ctrl+Alt+D`）
  - 弹幕窗进入 / 退出仅输入框模式（默认 `Ctrl+Alt+B`）
  - 直播音频播放 / 暂停、音频静音（默认未绑定）
- **应用内快捷键**：界面放大 / 缩小 / 重置（默认 `Ctrl+=` / `Ctrl+-` / `Ctrl+0`）同样可改绑；`Enter` 发送、`Esc` 关闭对话框与下拉框为固定惯例键

## 日常使用与维护

- **消息保留数量**：三栏共用缓存上限；填 0 表示不限制，整场直播的消息全部保留在内存（批量写入优化下 10 万条实测流畅）
- **图片缓存管理**：查看封面/头像与表情缓存占用，分类清理或一次清除
- **习惯保存在本机**：设置、常用房间、排序、收藏、消息模板和表情收藏均保存在本地 SQLite
- **更新与帮助**：定期检查更新，可手动检查、阅读更新日志并下载安装包
- **礼物打赏（可选编译）**：发送礼物默认不包含在官方构建里，需自行编译开启，详见项目 README
