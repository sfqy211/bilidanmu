# 账号与登录

BiliDanmu 支持多账号管理，并提供 B 站 TV 端二维码登录方式，方便你在不同账号之间快速登录与切换。

## 登录方式

### TV 二维码登录（当前唯一登录方式）

1. 在「账号」页面点击「添加账号」
2. 阅读应用内的风险提示，点击「我已知晓，继续」
3. 弹出 180px 二维码后，使用哔哩哔哩 App 扫描并确认
4. 页面每 3 秒轮询一次授权状态，确认后自动完成登录

登录成功后 BiliDanmu 会把凭证保存到本地，下次启动自动恢复。

> 说明：Rust 侧还存在 `login_by_cookie` 命令，用于直接导入 Cookie 字符串，但界面没有暴露入口。

## 多账号管理

- **添加账号**：可以同时保存多个账号
- **切换账号**：在账号列表中切换主账号；有弹幕窗口打开时会提示先关闭
- **切换发送账号**：在弹幕窗的功能栏里通过账号切换器单独设置发送身份，观看与收听继续用主账号
- **匿名模式**：账号页可切换到匿名模式，只接收弹幕与音频流
- **移除账号**：移除后本地凭证同步清除，同样要求先关闭弹幕窗口
- **自动恢复**：启动时自动恢复上次登录状态
- **刷新信息**：重新拉取头像、昵称等账号元信息
- **更新授权**：手动续期 Cookie，延长授权有效期
- **有效期显示**：账号行会显示授权剩余天数或「已过期」

## 双凭证机制

BiliDanmu 内部维护两套凭证：

| 凭证 | 用途 |
| --- | --- |
| 主凭证 | WebSocket 连接、音频流等观看相关 |
| 发送凭证 | 发送弹幕、表情、礼物等互动相关 |

发送凭证未设置时自动回退到主凭证，方便单账号用户使用。

## 匿名模式

- 侧栏底部显示「匿名模式」，主界面顶部常驻一条提示：仅可接收弹幕和音频流
- 弹幕窗中发送按钮、表情按钮、礼物按钮、循环发送均被禁用
- 弹幕窗功能栏的账号切换器显示「匿名模式」标记
- 收藏夹、稍后再看、评论点赞与发布需要登录
- 匿名模式下仍可浏览房间列表、接收弹幕、收听直播音频

## 安全提示

- 凭证数据仅保存在本机（tauri-plugin-store 的 `credential.json`），不会上传到任何服务器
- 建议不要在公共设备上保存账号
- 移除账号会清除本地存储的敏感信息

## 常见问题

**Q：登录后提示「账号未登录」？**

A：请检查 Cookie 是否过期，或尝试重新扫码登录、更新授权。

**Q：切换账号时提示要先关闭弹幕窗口？**

A：房间连接期间有弹幕窗口存在，账号切换会改变正在使用的凭证，因此必须先退出直播间。

**Q：切换账号后弹幕发送身份未更新？**

A：确认已在弹幕窗功能栏的账号切换器中选择了目标发送账号。
