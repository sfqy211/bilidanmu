# 快速开始

BiliDanmu 把 B 站直播弹幕和视频音频放进桌面。先安装软件，再用左侧导航在「直播间」和其它页面之间切换。

## 1. 下载并安装

前往 [下载最新版](https://github.com/sfqy211/bilidanmu/releases/latest)，在发布页的 **Assets** 中选择对应平台的安装包：

| 平台 | 安装包 |
| --- | --- |
| Windows 10 / 11（x64） | `.exe` 或 `.msi`，下载其中一种 |
| macOS（Universal，Apple Silicon + Intel） | `.dmg` |
| Linux（x64） | `.AppImage` |

Windows 双击安装包按提示完成安装，然后从开始菜单打开 BiliDanmu。macOS 版暂未签名公证，首次打开需右键应用选择「打开」。

如果 Windows 上启动提示缺少 WebView2，请安装 [Microsoft WebView2 运行时](https://developer.microsoft.com/microsoft-edge/webview2/)，再重新打开软件。

## 2. 选择登录或匿名使用

打开「账号」，点击「添加账号」，阅读应用内风险提示后，使用哔哩哔哩 App 扫描二维码并确认。登录成功后账号保存在本机，后续启动自动恢复；也可以添加多个账号并切换使用。

如果暂时只想看弹幕、听直播，可以在「账号」页选择「匿名模式」。匿名模式下侧栏会常驻一条提示：仅可接收弹幕和音频流。发送弹幕、表情、礼物、自动发送与自动点赞都不可用；收藏夹、稍后再看、评论点赞与发布也需要登录。

有弹幕窗口打开时无法切换账号或切换到匿名模式，请先关闭弹幕窗口。

## 3. 进入一个直播间

BiliDanmu 的页面切换全部在左侧导航栏完成，没有额外的模式开关：

| 导航项 | 页面 |
| --- | --- |
| 直播间 | 已添加的直播间列表 |
| 账号 | 登录与多账号管理 |
| AI 接入 | 占位页（开发中） |
| 听视频 | 收藏夹、稍后再看与视频播放 |
| 设置 | 全部设置（固定在导航栏底部） |

进入直播间的步骤：

1. 在侧栏点击「直播间」。
2. 点击右上角「添加」进入添加子页，按主播名、直播间号、直播链接或 UID 搜索，或直接从「正在直播的关注」里点加号。
3. 回到列表，点击房间行右侧的「打开弹幕」按钮（封面视图下是卡片右下角悬停出现的按钮）进入。列表按「全部 / 直播中 / 未开播」分区，直播中的房间排在前。
4. 弹幕窗口打开后可以查看礼物、弹幕和活动消息；点击音频按钮即可听直播声音。

进入直播间后主窗口会收起。想回到主窗口，请使用弹幕窗口上的「退出直播间」按钮。

## 4. 把窗口放到顺手的位置

**调透明度。** 弹幕窗口的「设置」面板里可调背景透明度（10–100%），也可以在主窗口「设置 → 弹幕窗口」中调整。

**贴边收起。** 拖动窗口标题栏，把窗口移到屏幕左侧、右侧或顶部边缘并松手。收起后窗口会缩成一条 14px 细条（垂直或水平居中于原位置）；鼠标靠近即展开，移开约 250ms 后自动收回。想恢复普通窗口，展开后把它拖离屏幕边缘。如果无法拖动，请先取消「锁定位置」。不想要收起条时可在设置里关掉「显示收起条」。

**置顶、透传与隐身。** 标题栏的「置顶」让弹幕保持在其他窗口上方；「窗口透传」让非交互区域的鼠标点击落到后面的应用，按钮和输入区域仍可操作；「隐身」让窗口在鼠标离开后完全透明并穿透，鼠标移回时淡入——适合完全不想被打扰的场景。

**仅输入框模式。** 标题栏的「仅输入框模式」把整个弹幕窗收成一行输入栏，只留输入框、发送、表情、恢复与拖动条，底边锚定不跳动；再按一次恢复完整窗口。

**隐藏到托盘。** 弹幕窗口右上角的关闭按钮会隐藏窗口，直播间保持连接（窗口也全程不进任务栏）。点击 Windows 任务栏右侧的 BiliDanmu 托盘图标即可再次显示；再次点击可以隐藏。右键托盘图标还能切换直播间、切换账号或退出软件。

主窗口关闭时的行为可在「设置 → 通用」中选择：每次询问、隐藏到托盘或退出程序。

## 5. 开始听视频

点击左侧导航的「听视频」，页面列出你的收藏夹与「稍后再看」；点击「添加视频」可按关键词搜索或粘贴 BV 号/链接。播放后离开播放页，主窗口底部的迷你播放条会继续控制播放。

完整操作见 [听视频指南](/guide/listen)。

## 常用设置

在「设置 → 外观」选择浅色、深色或跟随系统，从六套预设里挑一套配色，或单独调整强调色、背景、表面与前景色，并能调界面/内容字体与字号。设置改动会在停顿约 600ms 后自动保存，不需要点保存按钮。

| 操作 | 快捷键 |
| --- | --- |
| 显示 / 隐藏当前窗口（全局） | Ctrl + Alt + D |
| 仅输入框模式（全局） | Ctrl + Alt + B |
| 放大 / 缩小界面 | Ctrl + = / Ctrl + - |
| 恢复默认界面大小 | Ctrl + 0 |
| 调整弹幕字号 | Ctrl + 鼠标滚轮 |

软件会自动检查新版本，也可以在「设置 → 关于」中手动检查。如需反馈问题，请前往 [GitHub Issues](https://github.com/sfqy211/bilidanmu/issues)。
