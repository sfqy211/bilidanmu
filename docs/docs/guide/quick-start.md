# 快速开始

BiliDanmu 把 B 站直播弹幕和视频音频放进桌面。先安装软件，再从左上角选择「看直播」或「听视频」。

## 1. 下载并安装

前往 [下载最新版](https://github.com/sfqy211/bilidanmu/releases/latest)，在发布页的 **Assets** 中选择 Windows 安装包：`.exe` 或 `.msi`，下载其中一种即可。

目前提供 **Windows x64** 版本，适用于 Windows 10 及以上系统。双击安装包，按提示完成安装，然后从开始菜单打开 BiliDanmu。

如果启动提示缺少 WebView2，请安装 [Microsoft WebView2 运行时](https://developer.microsoft.com/microsoft-edge/webview2/)，再重新打开软件。

## 2. 选择登录或匿名使用

打开「账号」，点击「添加账号」，阅读应用内提示后，使用哔哩哔哩 App 扫描二维码并确认。登录成功后，账号会保存在本机，后续启动可恢复登录状态；也可以添加多个账号并切换使用。

如果暂时只想看弹幕、听直播，可以在「账号」页选择「匿名模式」。匿名模式不能发送文字或表情弹幕，也不能使用自动发送、自动点赞；评论点赞、发布和回复同样需要登录。读取自己的收藏夹和稍后再看列表，也需要账号。

## 3. 进入一个直播间

1. 点击左上角模式切换，选择「看直播」。
2. 在「直播间」页点击「添加」，按主播名、房间号、直播间链接或 UID 搜索。
3. 将需要的直播间加入列表，再从列表进入。
4. 弹幕窗口打开后，可以查看弹幕、礼物和活动消息；点击音频播放按钮即可听直播声音。

进入直播间后，主窗口会收起。想回到主窗口，请使用弹幕窗口上的「退出直播间」按钮。

## 4. 把窗口放到顺手的位置

**调透明度。** 在弹幕窗口的设置中调整不透明度。数值越低，越容易透过窗口看到后面的工作页面；也可以在主窗口「设置 → 弹幕窗口」中调整。

**贴边收起。** 拖动窗口标题栏，把窗口移到屏幕左侧、右侧或顶部边缘并松手。收起后，将鼠标移到边缘的小条上，窗口就会展开；鼠标离开后会自动收回。想恢复普通窗口，展开后将它拖离屏幕边缘。如果无法拖动，请先取消「锁定位置」。

**置顶与透传。** 标题栏的「置顶」让弹幕保持在其他窗口上方；「窗口透传」让非交互区域的鼠标点击落到后面的应用，按钮和输入区域仍可操作。

**隐藏到托盘。** 弹幕窗口右上角的关闭按钮会隐藏窗口，直播间保持连接。点击 Windows 任务栏右侧的 BiliDanmu 托盘图标即可再次显示；再次点击可以隐藏。右键托盘图标还能切换直播间、账号或退出软件。

主窗口关闭时的行为可在「设置 → 通用」中选择：每次询问、隐藏到托盘或退出程序。

## 5. 开始听视频

回到主窗口，点击左上角切换到「听视频」。你可以选择以下任意入口：

- 在「收藏夹」页顶部粘贴 BV 号或包含 BV 号的视频链接，点击「播放」。
- 在「搜索视频」中输入关键词，点击一个搜索结果开始听。
- 登录后打开自己的收藏夹或「稍后再看」，选择条目连续播放。

播放器提供进度、音量和切曲控制。有原有字幕的视频可以跟随字幕阅读，点击某句就能跳转到对应位置。离开播放页后，音频继续播放，主窗口底部的小播放条仍可暂停、切曲或停止。

完整操作见 [听视频指南](/guide/listen)。

## 常用设置

在「设置 → 外观」选择浅色、深色或跟随系统，调整配色、字体和字号。修改可以即时预览，点击「保存设置」后，下次启动仍会保留。

| 操作 | 快捷键 |
| --- | --- |
| 放大 / 缩小界面 | Ctrl + + / − |
| 恢复默认界面大小 | Ctrl + 0 |
| 调整弹幕字号 | Ctrl + 鼠标滚轮 |

软件会自动检查新版本，也可以在「设置 → 关于」中手动检查。如需反馈问题，请前往 [GitHub Issues](https://github.com/sfqy211/bilidanmu/issues)。
