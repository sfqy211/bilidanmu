# 弹幕收发

弹幕是 BiliDanmu 的核心功能。本章介绍如何发送与接收弹幕。

## 实时接收

BiliDanmu 通过 **WebSocket 长连接** 实时接收直播间消息，包括：

- **弹幕**：普通文字弹幕、表情弹幕
- **礼物**：投喂礼物、连击礼物（兼容 `SEND_GIFT` 与新版 protobuf 的 `SEND_GIFT_V2`）
- **进场**：`INTERACT_WORD` 与 `INTERACT_WORD_V2` 两种格式
- **醒目留言**：`SUPER_CHAT_MESSAGE` 及其 `_JPN` 变体，真实颜色还原
- **上舰**：`GUARD_BUY`
- **点赞**：`LIKE_INFO_V3_CLICK` 与总点赞数
- **直播状态**：`LIVE` / `PREPARING` 开播与下播提示、开播时长、在线人数、累计看过人数
- **标题变更**：主播直播中修改标题，弹幕窗标题栏即时跟随

## 发送弹幕

### 文字弹幕

1. 在弹幕输入框输入文字
2. 按回车或点击发送按钮
3. 弹幕会使用当前选中的发送账号发送

> 输入法选词期间的回车不会误发送（同时看 composition 状态与结束后 80ms 的宽限期）；输入内容上限 40 字，拼音组合中允许暂时超出、上屏后自动截断。

### 表情弹幕

1. 点击表情按钮打开「表情选择器」
2. 选择一个表情即可直接发送（大表情）
3. 表情包可点「管理表情包」按房间/账号隐藏或显示
4. 点表情上的星标可加入「收藏」包

## 弹幕渲染

- **内联表情**：`[微笑]` 等标签自动替换为表情图片，「表情显示」设为「不显示」时纯表情弹幕整条略过
- **醒目留言**：礼物栏保留完整卡片 + 背景图，弹幕栏可额外显示简化行
- **用户信息**：昵称、粉丝牌、荣耀等级、房管标志、高能榜排名，各自可单独隐藏
- **金额胶囊**：礼物、醒目留言、上舰按档位着色并前置价格；也可设为与普通弹幕一致
- **图片代理**：通过本地代理加载图片，绕过 CDN Referer 防盗链

## 弹幕过滤

- 按关键词或用户屏蔽（设置或弹幕窗的「屏蔽管理」面板中配置，对所有直播间生效）
- 右键任意消息可「复制昵称」「复制内容」「屏蔽此用户」「打开主页」
- 礼物栏按类型（送礼 / 上舰 / 醒目留言）与电池数量筛选
- 活动栏选择显示全部、只看进场或只看点赞，也可隐藏活动栏
- 表情可显示为图片、文字或整体隐藏

## 三栏布局

弹幕窗从上到下是：

| 区域 | 内容 |
| --- | --- |
| 礼物栏 | 送礼、醒目留言、上舰消息 |
| 弹幕栏 | 普通弹幕与进场/点赞之外的互动 |
| 活动栏 | 进场与点赞，三态：滚动列表 / 只看最新 / 隐藏 |

两处可拖拽的分隔条用于调整栏高（双击重置，方向键微调）；把某栏拖到极小会自动收起，拖回来恢复。

## 常见问题

**Q：弹幕发送失败？**

A：请检查账号是否登录、是否被禁言、或网络连接是否正常。匿名模式下发送按钮不可用。

**Q：弹幕延迟较高？**

A：WebSocket 连接通常是实时的，延迟过高请检查网络状况。连接时会自动探测各弹幕服务器并选择延迟最低的节点。
