# AI 接入

「AI 接入」页面把本应用的能力通过 **MCP（Model Context Protocol）** 暴露给外部
AI 客户端。启动应用后打开这一页，可以查看服务地址、复制访问 token 与客户端配置。

> 说明：这里不内置大模型，也不联网调用任何 AI 服务。AI 能力由你在外部客户端
> （Claude Code / Cursor / Cline / MCP Inspector 等）里使用，本应用只负责提供
> 工具与权限控制。项目历史上的外部 AI 服务集成已被整体移除，数据库里的
> `ai_models` 表是遗留结构。

## 启用服务

MCP 服务默认随应用启动，监听 `http://127.0.0.1:23332/mcp`。

- 端口固定，只绑 `127.0.0.1`，外部机器无法访问
- 端口被占用时服务会降级为不启动，页面显示错误原因，应用其余功能不受影响
- 可以用页面上的「停止 / 启动」开关随时切换

## 访问 token

任何请求都必须带 `Authorization: Bearer <token>`。token 首次启动自动生成，
可在页面上「显示 / 复制 / 重置」。重置后旧 token 立即失效，已连接的客户端需要
更新配置。

## 客户端配置

页面上提供可直接复制的 JSON 片段：

```json
{
  "mcpServers": {
    "bilidanmu": {
      "type": "http",
      "url": "http://127.0.0.1:23332/mcp",
      "headers": { "Authorization": "Bearer <token>" }
    }
  }
}
```

贴进客户端的 MCP 配置即可。协议版本支持 `2025-06-18`、`2025-03-26`、
`2024-11-05`。

## 权限模式

AI 调用工具时遵守页面上选择的三档之一：

| 模式 | 行为 |
| --- | --- |
| 变更前确认 | 执行任何非只读操作前都先询问你 |
| 自主模式（默认） | 只读与普通写操作直通；发弹幕、发评论、送礼等有风险的操作需确认 |
| 完全访问 | 全部自动执行，不再询问，包括送礼等真实扣费操作 |

需要确认时，主窗口会弹出对话框，显示 AI 要做什么（例如「发送弹幕：xxx」
「赠送礼物 #123 × 2，合计 2.00 元（真实扣费）」）。若你当时在弹幕窗口，主窗口会
临时显示出来，你决定后自动隐藏回去。超过 55 秒未响应按拒绝处理。

## 能做什么

工具分八类，完整清单（名称、用途说明、参数结构、风险等级）见
[MCP 工具参考](../api/mcp)——那是写给 AI 客户端看的，客户端连上来就能通过
`tools/list` 自动拿到，页面不再重复展示：

- **应用与直播上下文**：应用状态、当前直播间全貌（标题/人气/在线/弹幕速率/最近
  弹幕/礼物汇总）、按关键词检索弹幕、实时指标
- **账号**：账号列表、当前登录态、瓜子余额、切换账号、删除账号
- **房间**：已保存房间、搜索房间、房间详情、开播状态、关注的主播在播、进入/离开直播间
- **弹幕**：发送文字/表情弹幕、直播间点赞、表情包列表、消息模板增删改查
- **礼物**：礼物面板、礼物背包、送礼物（真实扣费，官方构建默认未编译）
- **视频**：搜索、详情、字幕、评论与楼中楼、收藏夹、稍后再看、播放/停止、评论点赞与发表
- **设置**：读取设置、按白名单修改（发送间隔、频率限制、风控、接收、过滤）

只读工具在任何模式下都直接放行。窗口几何、缓存清理、文件打开这类界面管道
不对外暴露。

## AI 日志

工具清单与调用记录不在页面上展示，而是写在 AI 专用日志 `ai.log` 里——与主应用
日志同目录，可在「设置 → 关于 → 日志目录」打开查看。每次应用启动记录当前工具
清单；每次工具调用记录工具名、结果、耗时、参数摘要。排查「AI 为什么没做成某
事」「客户端为什么看不到某工具」时看这个文件。文件超过 1MB 时下次启动自动
轮转为 `ai.log.old`。

## 安全性

- 服务只监听回环地址，且必须持 token，同机其它进程无法在不知道 token 的情况下调用
- 送礼相关能力由编译期开关 `gift-send` 控制，官方发布默认关闭；未启用时相关工具
  返回 `FEATURE_DISABLED`，运行时无法绕过
- 发弹幕经过应用的发送队列，遵循你设置的发送节奏，且 20 秒内相同文案会被拒绝
