# 循环发送与自动点赞

BiliDanmu 把自动发送与自动点赞放在**同一个面板**里——弹幕窗功能栏的「循环发送」按钮（紧凑模式下收进 `+` 菜单），面板内分三个 Tab。

## 打开面板

在弹幕窗功能栏点击闪电图标（`循环发送`）。匿名模式下按钮禁用。

## 三个 Tab

| Tab | 说明 |
| --- | --- |
| 文字 | 每行一条文字弹幕，按顺序循环发送 |
| 表情 | 勾选若干表情弹幕，按选择顺序循环发送 |
| 点赞 | 设置参数批量自动点赞 |

## 文字 / 表情：间隔与限时

面板底部（点赞以外的 Tab）有两个参数：

| 参数 | 说明 |
| --- | --- |
| 间隔 | 每次发送之间的秒数，最小 0.3 |
| 限时 | 可选，达到该秒数后自动停止；留空或填 0 表示不限时 |

点右侧播放按钮开始，按钮变为停止。面板内会显示「最近发送」「当前条目索引」「累计发送」与停止原因。

## 点赞 Tab

| 参数 | 说明 |
| --- | --- |
| 目标总数 | 本次自动点赞的总目标数，上限 1000 |
| 批次大小 | 每批点赞数量，每批 ≤100 |
| 批次间隔 | 每批之间的秒数，最小 0.5 |

开始后显示进度条 `已发/目标`；完成后显示「✓ 点赞完成」。

## 停止条件

- **手动停止**：再点一次停止按钮
- **限时到点**：`auto-send-stopped` 的 `reason` 为 `time_limit`
- **错误**：发送失败时停止并展示错误
- **切换直播间**：切房会自动停止当前自动发送/自动点赞任务
- **退出直播间**：断开连接时同样停止

## 注意事项

- 自动发送与点赞功能请合理使用，避免违反 B 站社区规范
- 过高的发送频率可能导致账号被禁言
- 建议设置合理的间隔时间
