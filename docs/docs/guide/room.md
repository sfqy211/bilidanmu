# 房间管理

BiliDanmu 提供灵活的房间搜索与管理能力，帮助你快速进入目标直播间。

## 搜索方式

在「直播间」页点击右上角「添加」进入子页，顶部模式下拉框提供四种方式：

| 方式 | 示例 | 说明 |
| --- | --- | --- |
| 主播名字 | `某主播` | 模糊匹配主播昵称 |
| 直播间号 | `123456` | 直接输入房间号 |
| 直播链接 | `https://live.bilibili.com/123456` | 自动解析房间号 |
| UID | `123456` | 通过主播 UID 反查直播间 |

## 添加流程

1. 在「直播间」页点击右上角「添加」
2. 未搜索时默认展示「正在直播的关注」，可直接点击加号添加；点「刷新」重新拉取
3. 也可在顶部搜索框输入后回车或点「搜索」，在结果中点击加号
4. 添加成功后子页不自动关闭，可以连续添加多个主播
5. 点「返回」或浏览器返回回到直播间列表

匿名模式下「正在直播的关注」为空，需要先登录。

## 房间列表

- 顶部标题显示「N 个直播间 · NN 个直播中」
- 状态标签「全部 / 直播中 / 未开播」带计数，点击筛选
- 直播中的房间排在前，同一分组内按自定义顺序排列
- 默认后添加的房间排在前，可拖动行或卡片调整顺序（两种视图都支持），顺序会记住
- 工具条从左到右：搜索框（模糊匹配 UID、房间号、主播名、直播间标题）、管理收藏、只看收藏、刷新直播状态、列表/封面视图切换、「添加」按钮
- 直播中显示「已播 X 小时 XX 分」，未开播显示「上次直播」时间（今天/昨天带时刻，更早只到日期）
- 悬停房间行可对其星标收藏、打开弹幕、删除

## 收藏

- 点击房间行或卡片上的星标即可收藏，收藏保存在本机，与 B 站账号无关
- 工具条星标按钮切换「只看收藏」，再次点击恢复全部
- 收藏非空时可点「管理收藏」打开对话框批量取消收藏

## 从弹幕窗快速切换

弹幕窗标题栏的「切换直播间」按钮会拉取一次实时开播状态，只列出正在直播的已保存房间；点击即原地切换，不关闭窗口、不打断连接。托盘右键菜单的「直播间」子菜单行为相同（每次最多 10 项）。

## 小贴士

- 支持回车键直接搜索
- 链接粘贴后自动识别房间号，无需手动提取
- 刷新直播状态与进入房间时都会更新本地记录的标题与封面
