# 房间搜索

BiliDanmu 提供灵活的房间搜索能力，帮助你快速进入目标直播间。

## 搜索方式

| 方式 | 示例 | 说明 |
| --- | --- | --- |
| 主播名 | `某主播` | 模糊匹配主播昵称 |
| 房间号 | `123456` | 直接输入房间号 |
| 链接 | `https://live.bilibili.com/123456` | 自动解析房间号 |
| UID | `UID:123456` | 通过主播 UID 查找 |

## 搜索历史

- 搜索过的房间会保存在本地 **SQLite** 数据库
- 常用房间可加入收藏，快速访问
- 支持清除搜索历史

## 操作流程

1. 在侧边栏点击「房间」
2. 点击右上角「添加」进入添加主播子页
3. 未搜索时默认展示关注列表中正在直播的主播，可直接点击添加
4. 也可在顶部搜索框按主播名 / 房间号 / 链接 / UID 搜索后添加
5. 添加成功后子页不自动关闭，便于连续添加；点击「关闭」或「返回」回到列表

## 房间列表

- 直播中的房间优先显示，直播中与未开播各自按自定义顺序排列
- 默认后添加的房间排在前，可拖动房间卡片/行调整顺序（列表与封面两种视图都支持），顺序会记住
- 顶部筛选框支持模糊匹配 UID、直播间号、主播名字、直播间标题
- 顶部的刷新按钮可手动刷新房间开播状态

## 小贴士

- 支持回车键快速搜索
- 搜索结果按相关度排序
- 链接粘贴后自动识别房间号，无需手动提取
