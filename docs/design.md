# 视觉设计风格

> BiliDanmu 的设计语言定义。基于 Microsoft Fluent Design 2 规范，适配弹幕客户端场景。

---

## 一、设计哲学

**Fluent 透明** — 界面是内容的载体，不是内容本身。

弹幕窗口叠加在直播画面上，设计目标是「存在但不打扰」：背景尽可能透明，文字和图标浮在画面上方。

管理面板（主窗口）追求「干净层次」：通过阴影和背景色差异区分层级，不依赖硬边框。信息层级通过字号和颜色区分。

---

## 二、品牌个性

| 关键词 | 说明 |
|---|---|
| 透明 | 弹幕窗口半透明背景，不遮挡底层内容 |
| 层次 | 用阴影和背景色差异表达层级，非边框 |
| 克制 | 只展示必要信息，其余用图标表达 |
| 一致 | 所有窗口、所有页面遵循同一套视觉语言 |

---

## 三、色彩

### 3.1 品牌色

B 站粉色 `#FB7299` 作为强调色，用于品牌标识、主要操作按钮、活跃状态高亮。不大面积使用。

### 3.2 背景色

**管理面板**（不使用纯白，使用偏灰的中性色）：

| 层级 | 浅色模式 | 深色模式 |
|---|---|---|
| 页面背景 | `#f5f5f5` | `#0a0c14` |
| 卡片/容器 | `#ffffff` | `#12141e` |
| 输入框/控件 | `#f8f8f8` | `#1a1c24` |
| 悬浮/弹出 | `#ffffff` | `#1e2028` |

**弹幕窗口**：所有背景色支持全局透明度调节（0-100%），使用 `rgba()` + CSS 变量。

### 3.3 文字色

三个层级（参考 Fluent Neutral 色板）：

| 层级 | 浅色模式 | 深色模式 |
|---|---|---|
| 主文字 | `#242424` | `#ffffff` |
| 次文字 | `#616161` | `#a0a0a0` |
| 弱文字 | `#9e9e9e` | `#616161` |

### 3.4 功能色（语义色，仅用于状态反馈）

| 用途 | 色系 |
|---|---|
| 错误/危险 | 玫瑰红 |
| 成功 | 翠绿 |
| 警告 | 琥珀 |
| 信息 | 天蓝 |

---

## 四、圆角（Fluent Corner Radius Tokens）

统一使用 Fluent Design 圆角规范：

| Token | 用途 | 值 | Tailwind |
|---|---|---|---|
| None | 导航栏、Tab 栏 | 0px | `rounded-none` |
| Small | 小徽章、标签 | 2px | `rounded-sm` |
| Medium | 按钮、输入框、下拉框 | 4px | `rounded` |
| Large | 卡片、容器、面板 | 8px | `rounded-lg` |
| X-Large | 弹出层、浮窗 | 12px | `rounded-xl` |

**关键规则：**
- 所有卡片/容器统一 `rounded-lg`（8px）
- 所有输入框/按钮统一 `rounded`（4px）
- 弹幕窗口本身（最外层）也使用 `rounded-lg`
- 导航栏、Tab 栏不使用圆角

---

## 五、边框与描边

### 5.1 管理面板

- **卡片/容器**：无边框，通过 `shadow-sm`（浅色模式）或 `ring-1 ring-white/[0.06]`（深色模式描边）表达层次
- **输入框/选择框**：保留细边框 `border border-neutral-200 dark:border-neutral-700`，聚焦时 `ring-2 ring-pink-500/30`
- **分割线**：使用 `border-t border-neutral-200 dark:border-neutral-800`，不用纯色

### 5.2 弹幕窗口

- 无边框、无分割线
- 各区域通过背景透明度自然区分

---

## 六、字体

- **字体族**：系统字体栈（`-apple-system, "Segoe UI", system-ui, sans-serif`）
- **弹幕字号**：默认 14px，用户可调（Ctrl+滚轮）
- **标题**：`text-2xl`（24px），`font-semibold`
- **正文**：`text-sm`（14px）
- **辅助文字**：`text-xs`（12px）或 `text-[11px]`
- **统计数据**：`text-[11px]`，图标 + 数字组合

---

## 七、图标

- **图标库**：Lucide React
- **风格**：线性（stroke），不填充
- **功能按钮**：仅图标，无文字标签，鼠标悬停显示 tooltip
- **提交按钮**：保留文字（保存/登录/搜索/发送等）
- **尺寸**：功能按钮 14px，统计图标 12px

---

## 八、透明度

弹幕窗口支持全局透明度调节（0-100%），默认 90%。

- **100%**：完全不透明
- **50%**：半透明
- **0%**：完全透明，仅文字和图标可见

透明度设置持久化，独立于主题。

---

## 九、主题

支持三种模式：浅色、深色、跟随系统。

- 弹幕窗口背景色在深色/浅色模式下使用不同的 RGB 值，共享同一个透明度变量
- 管理面板通过 `dark` class 切换
- 主题切换即时生效，无需重启
