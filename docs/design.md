# 视觉设计风格

> BiliDanmu 的设计语言定义。所有前端页面和组件应遵循本规范。

---

## 一、设计哲学

**极简透明** — 界面是内容的载体，不是内容本身。

弹幕窗口叠加在直播画面上，设计目标是「存在但不打扰」：背景尽可能透明，文字和图标浮在画面上方，用户一眼能看到弹幕内容，而非被 UI 元素分散注意力。

管理面板（主窗口）则追求「干净克制」：大量留白、无多余装饰、信息层级通过字号和颜色区分，而非边框和卡片。

---

## 二、品牌个性

| 关键词 | 说明                                 |
| ------ | ------------------------------------ |
| 透明   | 半透明背景，不遮挡底层内容           |
| 极简   | 无边框、无分割线、无多余装饰         |
| 克制   | 只展示必要信息，其余用图标表达       |
| 一致   | 所有窗口、所有页面遵循同一套视觉语言 |

---

## 三、色彩

### 3.1 品牌色

B 站粉色 `#FB7299` 作为强调色，用于品牌标识、主要操作按钮、活跃状态高亮。不大面积使用。

### 3.2 背景色

背景色分为三层透明度，从外到内依次加深：

| 层级   | 浅色模式 | 深色模式 |
| ------ | -------- | -------- |
| 主背景 | 浅灰白   | 近黑色   |
| 栏/条  | 纯白     | 深灰     |
| 面板   | 纯白     | 略深灰   |

弹幕窗口的所有背景色均支持全局透明度调节（10-100%），0% 时完全透明，仅文字和图标可见，但限制最低10%。

### 3.3 文字色

三个层级：主文字（高对比）、次文字（中等对比）、弱文字（低对比，用于辅助信息）。深色模式下自动切换为对应亮度。

### 3.4 功能色

| 用途      | 色系               |
| --------- | ------------------ |
| 错误/危险 | 玫瑰红             |
| 成功      | 翠绿               |
| 警告      | 琥珀               |
| 信息      | 天蓝               |
| 活跃状态  | 翠绿（半透明背景） |

---

## 四、字体

- **字体族**：系统字体栈（`-apple-system, "Segoe UI", system-ui, sans-serif`）
- **弹幕字号**：默认 14px，用户可调（Ctrl+滚轮）
- **标题**：`text-2xl`（24px），`font-semibold`
- **正文**：`text-sm`（14px）
- **辅助文字**：`text-xs`（12px）或 `text-[11px]`
- **统计数据**：`text-[11px]`，图标 + 数字组合

---

## 五、布局与间距

### 5.1 弹幕窗口

- 紧凑布局，无多余间距
- 标题栏和控制栏高度约 28px
- 功能按钮 `p-1.5`，仅图标
- 弹幕区域内容紧贴边缘（`px-2.5 py-1`）

### 5.2 管理面板

- 侧边栏 64px 宽，仅图标
- 内容区 `p-6`（24px）
- 卡片间 `gap-4`（16px）

---

## 六、边框与分割

- **弹幕窗口**：无边框、无分割线。各区域通过背景透明度自然区分
- **管理面板**：使用细边框（`border-slate-300`）区分卡片，无内部分割线
- **分割栏**：1px 细线，半透明，8px 可拖拽热区

---

## 七、图标

- **图标库**：Lucide React
- **风格**：线性（stroke），不填充
- **功能按钮**：仅图标，无文字标签，鼠标悬停显示 tooltip
- **尺寸**：功能按钮 14px，统计图标 12px

---

## 八、交互反馈

- **hover**：背景色微微加深（浅色模式 `bg-slate-100`，深色模式 `bg-white/[0.04]`）
- **活跃态**：翠绿半透明背景
- **危险操作**：hover 时 `bg-rose-500` + 白色文字
- **消息提示**：带背景色的横幅，2 秒自动消失

---

## 九、透明度

弹幕窗口支持全局透明度调节（10-100%），默认 90%。

- **100%**：完全不正常，深色/浅色背景
- **50%**：半透明，背景和内容均可辨认
- **0%**：完全透明，仅文字和图标浮在画面上

透明度设置持久化，独立于主题（浅色/深色）。

---

## 十、主题

支持三种模式：浅色、深色、跟随系统。

- 弹幕窗口背景色在深色/浅色模式下使用不同的 RGB 值，共享同一个透明度变量
- 管理面板通过 `dark` class 切换
- 主题切换即时生效，无需重启
