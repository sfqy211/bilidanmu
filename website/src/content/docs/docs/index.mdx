BiliDanmu 把 B 站直播弹幕和视频音频放进桌面。弹幕窗可以透明、贴边收起、随时隐藏到托盘，也可以收成一行输入框；视频则在后台播放，字幕和弹幕留在眼前。

## 它解决什么问题

直播很好看，但网页播放器往往占满整块屏幕。BiliDanmu 把直播收进一个独立小窗：

- **弹幕浮在桌面上**：背景透明度可调，不挡手头的工作。
- **窗口贴着屏幕边缘**：鼠标靠近展开，移开缩成细线。
- **不打断当前任务**：仅输入框模式只留一行输入栏，回车即发。
- **视频也能听**：收藏夹和稍后再看整表入队，字幕逐句跟随。
